# Insider_Threat_Detection
Insider Threat Detection is a Python-based system that monitors user activity, detects suspicious behavior, and logs FTP access using a honeypot. Features include a web dashboard, PDF/email reporting, machine learning analysis, and a custom FTP client for testing.
What is this project?
This is a software system designed to monitor and detect suspicious or malicious activities inside an organization’s computer network. Its goal is to catch insider threats, like unauthorized access, data theft, or malicious actions by employees or guests, before they cause damage.

Major Components and What They Do
1. Backend Server (Flask App)
Written in Python, it runs a small web server.
Hosts a dashboard (web pages) you open in your browser to see real-time alerts, logs, and reports.
Handles all communication between your browser and the monitoring system.
Routes like /dashboard or /reports show the data collected.
Powers the machine learning (ML) analyzer that studies the security logs to detect threats.

2. Security Monitor
This is a program running in the background monitoring your system's security-related logs.
On Windows, it reads the Windows Security Event Logs for login attempts, privilege changes, etc.
On Linux, it monitors log files like /var/log/auth.log for SSH logins, sudo commands, failures, etc.
When it detects noteworthy events, it saves them into a local SQLite database.
If it can't get real logs (no permissions, missing files), it generates simulated events for demonstration.

3. FTP Honeypot
A special fake FTP server that pretends to offer file transfer service.
It is designed to detect unauthorized FTP access attempts.
It runs on port 2121 of your machine.
Supports multiple fake user accounts, but any interaction gets logged.
If someone tries to connect, login, upload or download files, this activity is recorded and analyzed.
Acts like a bait to catch suspicious insiders or attackers.

4. Machine Learning Analyzer
Uses collected logs (event logs, FTP logs) to find suspicious behavior.
Trains models to detect anomalies, risk levels, and potential threats.
Flags high-risk activities and generates report entries.
Applied periodically to analyze new logs in the database.

5. SQLite Database
Local file storage for all events, logs, and reports.
Stores security event records, FTP activity logs, generated suspicious reports, and ML model data.
Keeps everything organized and easily queryable from Python.

6. Frontend Dashboard (HTML & Flask Templates)
Made with HTML files (using Flask’s Jinja2 templating engine).
Shows collected data in tables and charts.
Allows filtering and reviewing reports.
Accessible from your browser at http://localhost:5000 (or via ngrok for remote access).
You can also download the reports created as PDF and send them to an email address directly from the dashboard.

7. Ngrok (Optional)
A tool that creates a temporary public URL for your local Flask web server.
Useful when you want to access your dashboard remotely over the Internet.
Creates a secure HTTPS tunnel to your local server.

How It Works Together
- Start the Flask backend app: launches everything including the FTP honeypot and security monitors.
- Security monitor collects live system events (logins, file accesses, FTP attempts).
- Those events get logged to the SQLite database.
- The ML analyzer periodically scans these logs to find suspicious behavior using trained models.
- Suspicious events are flagged and detailed reports created.
- You open the web dashboard (locally or remotely via ngrok) to see alerts, activity logs, FTP access attempts, and reports.
- You can test FTP honeypot by connecting with FTP clients and performing operations, which get logged.

What You Can Do
- View insider threat activity in real time via a web browser.
- Configure and customize FTP honeypot to simulate files and users.
- Review suspicious reports generated by ML detection.
- Download reports as PDF or send them via email directly from the dashboard.
- Extend system to add email alerts or connect with other security tools.
- Learn how system and network monitoring work in practice.

## Requirements

**Python:**  
- Python 3.8 or higher  
- pip (Python package manager)  
- (Recommended) virtualenv for isolated environments

**Python Packages:**  
Install all requirements with:
```
pip install Flask Flask-Mail Flask-SQLAlchemy pandas scikit-learn matplotlib pyftpdlib reportlab jinja2 psutil pdfkit pyngrok
```
- Flask (web framework)
- Flask-Mail (email sending)
- Flask-SQLAlchemy (ORM for SQLite)
- pandas, scikit-learn, matplotlib (data analysis & ML)
- pyftpdlib (FTP honeypot)
- reportlab (PDF generation, if used)
- jinja2 (templating)
- psutil (system info)
- pdfkit (HTML to PDF conversion)
- pyngrok (for public dashboard access)
- pywin32 (only on Windows, for event log access; install with `pip install pywin32`)

**External Tools:**

- **wkhtmltopdf**  
  Required for PDF generation via pdfkit.  
  Download and install from: https://wkhtmltopdf.org/downloads.html  
  Make sure the executable path matches your code or is in your system PATH.

- **Ngrok (optional, for remote access)**  
  Download from: https://ngrok.com/download  
  Sign up for a free account to get your Auth Token (if you want to use authenticated tunnels).

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. (Optional but recommended) Create and activate a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate   # On Windows
   source venv/bin/activate  # On Linux/Mac
   ```
4. Install the requirements as shown above.
5. Start the Flask app:
   ```
   python db_init_enhanced.py
   python app_corrected.py
   ```
6. Open your browser and go to: [http://localhost:5000](http://localhost:5000)
7. To access remotely, install ngrok and run:
   ```
   ngrok http 5000
   ```
   Use the generated public URL to access the dashboard from anywhere.

**Important Configuration:**
- You must add your Ngrok Auth Token in the code (see `NGROK_AUTH_TOKEN` in `app_corrected.py`) if you want to use ngrok for remote access.
- For email sending features, you must set your email address and password in `app_corrected.py` (look for the Flask-Mail or email configuration section).
**Make sure to disable any firewall or allow port 2121 and 5000 through your firewall to ensure the FTP client and dashboard can connect to the honeypot and web server without issues.**


**Notes:**
- The FTP honeypot runs on port 2121. You can test it using any FTP client(eg. Filezilla).
- Reports can be downloaded as PDF or sent via email from the dashboard interface.
- For email features, configure your email settings in the app's configuration file or environment variables.

## Custom File Client

You can use the provided custom file client to interact with the FTP honeypot. This client allows you to connect, upload, download, and test the honeypot’s detection features using a graphical interface.

**Location:**  
`ftp client/simple_ftp_client.py`

**Features:**
- Connects to the FTP honeypot running on port 2121
- Supports login, upload, download, directory creation, and file listing
- GUI built with Tkinter for easy use
- Includes test buttons for admin login, anonymous login, and multiple failed logins to trigger honeypot alerts
- Activity log window for all actions

**How to Run:**
1. Make sure the FTP honeypot is running (see above).
2. Open a terminal in the project directory.
3. Run the client:
   ```
   python "ftp client/simple_ftp_client.py"
   ```
   (Adjust the path if your directory structure is different.)

**Dependencies:**  
- Python 3.x
- Tkinter (comes with standard Python installation)
- No extra packages required beyond the Python standard library

**FTP Honeypot Usernames and Passwords to Try:**
- `admin` / `admin123`
- `administrator` / `password`
- `ftpuser` / `ftp123`
- `backup` / `backup2024`
- `service` / `service123`
- `guest` / `guest`
- `test` / `test123`
- `demo` / `demo123`
- `upload` / `upload123`
- `user` / `password123`
- **Anonymous login is also enabled** (leave username as `anonymous` or blank, no password required)

**Usage:**  
- Enter the FTP server address (default is `192.168.1.100`) and port (`2121`).
- Enter one of the usernames and passwords above.
- Click **Connect** to connect to the honeypot.
- Use the buttons to list files, upload, download, or create directories.
- Use the "Honeypot Testing" buttons to simulate suspicious activity and see how the honeypot and dashboard respond.
